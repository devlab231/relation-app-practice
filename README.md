# relation-app-practice

## 概要
COACHTECH 教材 Tutorial 9-5「リレーション ハンズオン演習」で作成した成果物です。<br>
Eloquent ORMのリレーションを利用して、投稿一覧・投稿詳細の表示、タグによる絞り込み、コメント件数の表示などを実装しました。

## 使用技術
- PHP 8.5.12
- Laravel 10.50.3
- Eloquent ORM（hasMany / belongsTo / belongsToMany）
- MySQL

## 学んだこと
- Eloquent ORMのリレーション
- 関連データの取得
- 条件付き検索と並び替え

## 動作確認
GitHubから本プロジェクトを取得し、Laravel Sailを使用して起動することで動作確認できます。<br>
ブラウザで投稿一覧ページが正常に表示されることを確認してください。<br>
※ 実行にはDocker環境および初期設定が必要です。
